# DeepSeek-V4 架构详解

## 一、架构总览

DeepSeek-V4 系列包含两个 MoE 语言模型：

| 模型 | 总参数 | 激活参数 | 上下文长度 | 精度 |
|:---|:---|:---|:---|:---|
| DeepSeek-V4-Pro | 1.6T | 49B | 1M | FP4 + FP8 Mixed |
| DeepSeek-V4-Flash | 284B | 13B | 1M | FP4 + FP8 Mixed |

核心升级点：

1. **Hybrid Attention Architecture:** 结合 Compressed Sparse Attention (CSA) 和 Heavily Compressed Attention (HCA)，在 1M-token 上下文下，推理 FLOPs 仅需 V3.2 的 27%，KV Cache 仅需 10%
2. **Manifold-Constrained Hyper-Connections (mHC):** 强化传统残差连接，增强信号传播稳定性
3. **Muon Optimizer:** 替代 AdamW，更快收敛、更稳定
4. **FP4 + FP8 混合精度:** MoE 专家参数使用 FP4，其余参数使用 FP8
5. **训练数据 >32T tokens**，后训练采用两阶段范式（独立培养领域专家 + on-policy distillation 统一整合）
6. **三种推理模式:** Non-think / Think High / Think Max

### 8.2 三个核心区别

**区别1: 权重固定 → 权重可学习**

```
    传统:   y = x + F(x)           ← α=1, β=1, 死的
    V4:     y = α·x + β·F(x)      ← α,β 可训练, 活的

    浅层 (第1-10层)              深层 (第60-70层)
    ┌─────────────────┐         ┌─────────────────┐
    │ α≈1.2  β≈0.8   │         │ α≈0.3  β≈1.7   │
    │                 │         │                 │
    │ 多保留原始信息    │         │ 多强调变换结果    │
    │ 让embedding     │         │ 让高层特征      │
    │ 平稳过渡        │         │ 充分抽象        │
    └─────────────────┘         └─────────────────┘
```

**区别2: 无约束 → 流形约束**

没有约束时 α,β 可能趋向 0 或无穷，导致信号消失或爆炸。有流形约束后 α,β 被限制在合理区间，所有层的信号幅度保持一致。

**区别3: 只有加法 → 可以乘性调控**

传统残差中 F(x) 的改变幅度不可控。V4 中 β 控制 F(x) 的贡献度，α 控制原始信号的保留度，可以精确调控每层的"保守度"。

### 8.3 直观类比

- **传统残差** = 高速公路的"直通车道"：车流 100% 通过，服务区贡献 100% 加入，简单粗暴但无法调节
- **V4 mHC** = 智能匝道控制系统：每层独立调控，浅层 α 开大 β 关小（保留原始信息），深层 α 关小 β 开大（充分特征变换），流形约束 = 安全限速器，防止任何一层"失控"

## 九、流形约束详解

### 9.1 信号爆炸/消失是怎么发生的

```
   输入 x ──→ [层1] ──→ [层2] ──→ ... ──→ [层70] ──→ 输出
             │norm│    │norm│          │norm│
             ‖x₁‖     ‖x₂‖           ‖x₇₀‖

  情况A: 信号爆炸 (Exploding)
  ‖x₀‖=1 → ‖x₁‖=1.2 → ‖x₂‖=1.5 → ‖x₃‖=2.1 → ‖x₇₀‖=10¹²
  后果: 梯度 → ∞，loss → NaN，训练崩溃

  情况B: 信号消失 (Vanishing)
  ‖x₀‖=1 → ‖x₁‖=0.8 → ‖x₂‖=0.5 → ‖x₃‖=0.3 → ‖x₇₀‖≈0
  后果: 梯度 ≈ 0，深层什么都没学到

  问题根源: 1.1⁷⁰ ≈ 790 (爆炸!) | 0.9⁷⁰ ≈ 0.0006 (消失!)
```

### 9.2 流形如何防止爆炸/消失

"流形"是 (α, β) 参数对被限制在一个紧致曲线上（如 α²+β²=1 的单位圆），参数怎么学都跑不出这个圈。

常见约束流形:
- **单位球面约束 (Sphere):** α² + β² = 1，物理含义是能量守恒，α=cos(θ), β=sin(θ)，θ 是可学习参数，α,β 永远 ∈ [-1,1]
- **单纯形约束 (Simplex):** α + β = 1, α≥0, β≥0，输出是输入和变换的加权平均
- **范数约束:** ‖(α,β)‖ₚ ≤ C，确保 Lipschitz 常数有界

关键洞察：有约束时 ‖y‖ ≤ 1·‖x‖ + 1·‖F(x)‖，放大倍数有上界，α,β 不可能同时为 0（不会消失），70 层累积也在可控范围内。

## 十、mHC 完整定义

**mHC = Manifold-Constrained Hyper-Connections（流形约束超连接）**

- **Hyper-Connections:** 不只连接相邻层，而是可以跨多层连接，每个输出可以接收多个层的输入
- **Manifold-Constrained:** 施加于跨层连接权重上的流形约束

公式: y_l = Σ(i<j) α_{i→j} · x_i + Σ(i≤j) β_{i→j} · F_j(x_i)

其中 (α_{i→j}, β_{i→j}) 对必须落在某个流形上（如 α²+β²=1）。

## 十一、α/β 如何自适应调节

α/β 不是人为设定的，是通过梯度下降从数据中学出来的：

1. **参数化:** 不直接学 α 和 β，而是学底层参数 θ。例如 α=cos(θ), β=sin(θ)，θ 梯度更新不受限，但 α,β 自动满足 α²+β²=1
2. **梯度驱动分化:**
   - 浅层 ∂L/∂α > 0, ∂L/∂β < 0 → loss 说"保留更多原始信号" → α↑ β↓ → "保守层"
   - 深层 ∂L/∂α < 0, ∂L/∂β > 0 → loss 说"需要更多变换" → α↓ β↑ → "激进层"
3. 流形约束下 α↑ 必然伴随 β↓（因为 α²+β²=1），迫使每层在"保留"和"变换"间做 tradeoff

实际效果:
| Layer | α | β | 策略 |
|:---|:---|:---|:---|
| 浅层 (1) | ≈0.95 | ≈0.32 | 保守，保留 embedding 语义 |
| 中层 (35) | ≈0.5 | ≈0.87 | 平衡，逐步抽象 |
| 深层 (70) | ≈0.15 | ≈0.99 | 激进，深度特征变换 |
